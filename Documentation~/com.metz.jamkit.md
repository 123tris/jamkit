# JamKit Documentation

Rapid game-jam toolkit for Unity 6. Start with the [README](../README.md) for architecture and the component catalog; these pages are the hands-on guides:

- **[Hour Zero Checklist](hour-zero-checklist.md)** — the first ten minutes of a jam, in order.
- **[Feel integration](feel-integration.md)** — JamKit's own juice, and wiring Feel's feedbacks to the same signals.
- **[Debugging & runtime tuning](debugging-and-tuning.md)** — watching a feature work, from inspector buttons to the DebugPanel.

These guides double as manual test scripts: if a step doesn't work as written, that's a JamKit bug — file it.
