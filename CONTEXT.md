# JamKit

A rapid game-jam toolkit for Unity: the services, gameplay components, menus and editor tooling that make a new project playable in its first hour. Ripple owns state and events; JamKit owns the rest.

## Language

**Project template**:
The authored set of scenes, prefabs, assets and UI documents that a new JamKit project starts from.
_Avoid_: Scaffold (as a noun), template assets, boilerplate

**Scaffold**:
To give a project the files of the project template that it does not already have.
_Avoid_: Create, generate, set up

**Scaffolded project**:
A Unity project that has received the project template.
_Avoid_: Jam project

**Starter**:
A prefab in the project template that is dropped into a scene as a ready-made player, enemy, pickup, zone, spawner or camera.
_Avoid_: Preset, Lego brick
